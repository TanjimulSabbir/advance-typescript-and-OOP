## 🧠 OOP Concepts Covered

### 1. Encapsulation
Protects data inside a class using access modifiers like `private`, `public`, and `protected`.

### 2. Inheritance
Allows a class to reuse properties and methods from another class.

### 3. Polymorphism
Enables the same method to behave differently in different classes.

### 4. Abstraction
Hides internal implementation and shows only essential features.
